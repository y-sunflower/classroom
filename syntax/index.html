CSV tables¶

Use the <csv-table> element to load a CSV file as an interactive table. Tabulator parses the CSV and provides sorting and pagination; the table also includes a search across all columns.

<csv-table src="../data/sales.csv" caption="Sales transactions" page-size="10"></csv-table>

Set src to a path relative to the Markdown file. caption and page-size are optional; the default page size is 10.
